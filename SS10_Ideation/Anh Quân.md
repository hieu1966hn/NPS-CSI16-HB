Tên dự án: Hệ thống gợi ý phim
Link Dataset (Kaggle): https://www.kaggle.com/datasets/ahsanaseer/top-rated-tmdb-movies-10k, https://www.kaggle.com/datasets/ayushimishra2809/movielens-dataset?select=ratings.csv
Vấn đề cần giải quyết: Gợi ý phim phù hợp theo sở thích người dùng và giúp người dùng khám phá phim mới.
Kiến thức áp dụng:
CS Basic: Cấu trúc điều khiển, vòng lặp, hàm, xử lý chuỗi.
CS Advanced: Lập trình hướng đối tượng (OOP) để quản lý mô hình, xử lý ngoại lệ khi gọi API.
CS Intensive: Pandas (tiền xử lý dữ liệu), Scikit-learn (huấn luyện mô hình Random Forest), Matplotlib/Seaborn (trực quan hóa), Streamlit (xây dựng Web App), Generative AI (tích hợp API Gemini).
bổ sung: Botchat sẽ giúp users  gợi ý phim theo sở thích users qua cách users nhập: "Tôi thích phim hành động.", "Gợi ý phim giống Interstellar." Chatbot phân tích yêu cầu và đề xuất danh sách phim phù hợp.
