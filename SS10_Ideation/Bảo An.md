Tên dự án: Hệ thống dự đoán lượng calo đốt cháy và hỗ trợ lên kế hoạch tập luyện thông minh
Link Dataset (Kaggle): https://www.kaggle.com/datasets/fmendes/fmendesdat263xdemos
Vấn đề cần giải quyết: Hỗ trợ người tập thể thao theo dõi chỉ số sức khỏe, dự đoán chính xác lượng calo tiêu hao dựa trên nhịp tim và thời gian tập luyện thông qua mô hình học máy, đồng thời tích hợp trợ lý ảo thông minh để tư vấn lộ trình giảm cân và thực đơn dinh dưỡng.
Kiến thức áp dụng:

- CS Basic: Cấu trúc điều khiển, câu lệnh rẽ nhánh để phân loại BMI, vòng lặp, hàm xử lý chuỗi dữ liệu.
- CS Advanced: Lập trình hướng đối tượng (OOP) để quản lý thông tin người dùng và bài tập, đọc/ghi file CSV, xử lý ngoại lệ khi gọi API.
- CS Intensive: Pandas/NumPy (gộp và tiền xử lý dữ liệu), Scikit-learn (huấn luyện mô hình Random Forest Regressor), Matplotlib/Seaborn (trực quan hóa Dashboard sức khỏe với 8 biểu đồ), Streamlit (xây dựng Web App), Generative AI (tích hợp API Gemini làm PT ảo).
